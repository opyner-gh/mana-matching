# Custom Fonts Guide

Drop any `.ttf` or `.otf` font files into this `assets/fonts/` folder!

- If you drop **a single `.ttf` or `.otf` file** into `assets/fonts/` (for example, a hand-drawn RPG serif font), `FontManager` will automatically use it across the game.
- If you want distinct fonts for different text roles, name them:
  - `title.ttf` — Chapter headers & banners
  - `rune.ttf` — Word Pebble engravings
  - `keystone.ttf` — Category Keystone titles
  - `lore.ttf` — Grimoire lore notes & whisper bar
  - `ui.ttf` — HUD buttons & counters
